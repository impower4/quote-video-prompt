# 🎬 오디오북 영상 시스템 프롬프트 가이드

Claude Code로 **에이전트와 스킬 기반 오디오북 영상 시스템**을 설계·구현하는 프롬프트 모음입니다. 이 저장소는 실행 가능한 영상 제작 앱이 아니라 제작 가이드입니다.

2026-10-23: 스킬 발견 방식, 모델·보이스 설정, 승인·예산, 실제 발화 자막 검수 기준을 정리했습니다.

## 준비

[전체 프롬프트](prompt.md)에서 필요한 단계부터 시작하세요. 현재 프로젝트의 대본·이미지·보이스·비용 조건이 정해졌으면 그대로 이어갑니다.

- 생성 API를 사용할 때만 해당 제공자의 인증·현재 지원 모델·요금을 확인합니다. 특정 preview 모델이나 API 키를 모든 실행의 필수 조건으로 고정하지 않습니다.
- API 키는 환경변수 등 비밀 설정에서 읽고 소스와 로그에 저장하지 않습니다.
- 기존 음성·이미지나 무료 방법으로 가능한 작업은 먼저 확인합니다. 외부 생성 크레딧 0과 서비스 금지 조건을 유지합니다.
- 이 문서의 수정만으로 PC·휴대폰에 에이전트가 설치되지는 않습니다. 실제 설치 경로와 새 세션의 호출을 확인합니다.

## 제작 구성

| 기능 | 구현 방향 | 확인할 것 |
|---|---|---|
| 이미지 | 승인한 스타일과 현재 지원 모델 | 이미지 승인·연속성·비용 |
| 나레이션 | 승인한 TTS 또는 기존 음성 | 보이스 일관성·발음·실제 청취 |
| 자막 | 환경에 맞는 전사·정렬 도구 | 실제 발화와 타임스탬프 대조 |
| 합성 | FFmpeg 등 사용 가능한 편집 도구 | 해상도·프레임·오디오·잘림 |
| BGM | 사용 권한이 확인된 녹음 | 말소리 명료도·피크·덕킹 |

이미지와 실제 음성을 준비한 뒤 발화 기준 자막을 만들고 합성합니다. 파일 생성, 프레임 확인, 정상 속도 전편 재생, 청취는 별도로 기록합니다.

## 사용법

| 단계 | 목표 |
|---|---|
| 0 | Claude Code 스킬·에이전트 구조 확인 |
| 1 | 현재 요청과 승인 범위를 반영한 아키텍처 설계 |
| 2 | Python 모듈을 나눠 구현·검증 |
| 3 | `SKILL.md`와 사용 시점 작성 |
| 4 | 오케스트레이터와 콘텐츠 기획 에이전트 정의 |
| 5 | `/createvideo` 명령 연결 |
| 6 | 승인한 한 장면으로 검증한 뒤 요청 범위로 확장 |

원샷 프롬프트도 사용할 수 있습니다. 설계·구현 요청을 유료 생성·공개 게시까지 허가한 것으로 해석하지 않습니다. 이미 승인된 범위에서는 매 단계 확인을 반복하지 않습니다.

## 파일 역할

| 경로 | 역할 |
|---|---|
| `.claude/skills/<이름>/SKILL.md` | 프로젝트 스킬 |
| `.claude/agents/` | 역할별 에이전트 |
| `.claude/commands/createvideo.md` | 명시적 제작 명령 |
| `src/quote_video/` | 이미지·음성·자막·합성 모듈 |
| `assets/font/`, `assets/bgm/` | 사용 조건을 확인한 글꼴·음악 |

스킬은 지원 디렉터리에서 발견됩니다. `settings.json`에 스킬 목록을 등록할 필요는 없습니다. `allowed-tools`는 선택 항목이며 단순히 스킬을 만들기 위해 권한을 넓히지 않습니다. [Claude Code 공식 스킬 문서](https://code.claude.com/docs/en/skills)를 기준으로 현재 설치 환경을 확인합니다.

## 프로젝트 설정

| 항목 | 기본 예시와 원칙 |
|---|---|
| 이미지 스타일 | 연필 스케치 또는 미니멀 일러스트 중 채택한 한 방향 유지 |
| 모델 | 현재 지원·비용을 확인한 모델을 설정 한 곳에서 관리 |
| 보이스 | 승인한 목소리 유지. 후보를 자동 확정하지 않음 |
| 전사 | 환경·언어·속도를 검토해 선택하고 실제 발화로 검수 |
| 영상 | 새 오디오북 예시 1920×1080, 30fps. 기존 작품 설정 우선 |
| 페이드 | 0.5초는 시작 예시이며 내용·낭독에 맞춰 조절 |
| BGM | 고정 백분율 대신 실제 청취로 조절. 곡과 해당 녹음의 사용 조건 확인 |
| 글꼴 | 실제 설치·사용 권한·가독성을 확인한 글꼴 |

완성 나레이션 영상에서는 요청한 MP4·음성·실제 발화 SRT·확정 대본을 확인합니다. 썸네일·블로그·PDF는 요청 범위에 있을 때만 추가합니다.
